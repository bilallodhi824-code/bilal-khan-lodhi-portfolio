## 🏛️ Systems Overview & Architectural Features

- **Apple Dynamic Island Navigation:** A single morphing pill container that fluidly contracts into a compact beacon when idle and expands with spring kinematics on scroll or interaction, with zero flicker.
- **Color Token System:**
  - **Charcoal (`#0C0D12` / `#14151D`):** Deep obsidian canvas and frosted glassmorphic card foundations.
  - **Burgundy (`#9B1B30` / `#BE123C` / `#E11D48`):** Editorial accent, call-to-actions, and interactive card aura.
  - **Brilliant White (`#FFFFFF`):** High-contrast typography and accessibility compliance (>7:1 WCAG AAA).
  - **Royal Blue (`#2563EB` / `#3B82F6`):** Secondary telemetry glow, active system indicators, and focus rings.
- **Interactive Engineering Artifacts:**
  - 20+ Live Production Deployments with in-modal interactive sandboxes and direct APK downloads.
  - Deep-dive case studies covering enterprise architecture, bottlenecks, and verified performance metrics.
  - Built-in grounded BK AI Assistant with natural language guidance.
- **Performance & Latency:** Sub-18ms edge delivery, zero layout shifts (CLS 0.00), and 100/100 Core Web Vitals score.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17+ or 20.x
- npm, yarn, or pnpm

### Installation

```bash
git clone https://github.com/bilallodhi824-code/bilal-khan-lodhi-portfolio.git
cd bilal-khan-lodhi-portfolio
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build

```bash
npm run build
npm start
```
